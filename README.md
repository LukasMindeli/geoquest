# GeoQuestGitHub

Одностраничный статический веб-проект с основным приложением в `index.html`.
Проект разворачивается как static SPA и использует `vercel.json` для rewrite всех маршрутов на `index.html`.

## Структура

- `index.html` - основное приложение
- `sitemap.xml` - sitemap для домена
- `vercel.json` - конфигурация rewrite для Vercel
- `backups/` - локальные резервные копии, не добавляются в git

## Локальный запуск

### Вариант 1: Python

```bash
python -m http.server 8080
```

После запуска откройте:

```text
http://localhost:8080
```

### Вариант 2: serve

```bash
npx serve .
```

После запуска откройте адрес, который покажет `serve` в терминале.

## Примечание

Проект хранит основную логику в одном HTML-файле и загружает часть внешних библиотек и данных через CDN.
